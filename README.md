# APEX Engineer – Website

Statische Website für APEX Engineer, eine Formel-1-Ingenieurssimulation für macOS.
Die Seiten werden aus `tools/apex_web/` im Spielprojekt gebaut (`build_site.py`) und hier unverändert abgelegt.

Die Installationsdatei liegt nicht im Repository, sondern im Release [v2.10](https://github.com/mateo-gepard/apex-engineer/releases/tag/v2.10).
